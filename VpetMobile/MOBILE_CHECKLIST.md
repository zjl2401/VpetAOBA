# VpetMobile 对照复现清单（诚实版）

> 对照源：`VpetPNG/1.0/PRE_VOICE_BASELINE.md` + `FEATURES.md` + `pet.py`  
> 原则：对照抄行为与常量，不整包搬 `pet.py`；**桌面禁止为本需求大改**。  
> **交差门禁**：Phase 6 按基线逐条勾选通过后才算完成；壳/假 ✅ 不算交差。  
> 可视化计划：Cursor Canvas `vpet-mobile-repro-plan`

## 目标交互（与电脑版对位）

| 电脑版 | 手机版目标 |
|--------|------------|
| 无边框桌宠 + 右键四大菜单 + 快捷键 | **悬浮桌宠** + **点宠**四大菜单（≈快捷键） |
| 无 Launcher 控制壳 | **App 页只做认主/权限/开桌宠** → 启动后 **关掉 App 页**，只留悬浮 |
| 子功能多为桌宠旁弹窗 | 优先悬浮内完成；全屏页仅无法悬浮实现时用 |

**明确不做**：打字、背单词、天气预报、网易云云端歌单（本机音频可以）。  
**与桌面同 stub**：AI 对话、邀请、×生活。

## 基线核对（`PRE_VOICE_BASELINE` 第十二节 · 手机口径）

### 跳过（需求/平台）
- 打字游戏 G03；背单词 G05–G06；天气预报；网易云云端歌单
- AI / 邀请 / ×生活 → stub（与桌面同）
- Win32 色键 / 全局热键 / 显示层级三档 / ffmpeg 语音裁切 / 投稿本机 zip
- Silent Oath 独立进程全战役（手机为内嵌战役 + DIY）
- 家园经营锄种浇收（H-FARM-TOOLS-V2）玩法 → **已实现 MVP**（见 Phase 续作）

### 已知限制（可交差但非桌面像素级）
- GameClear 粒子为简化版；无 ffmpeg 语音裁切缓存
- border5 / 像素溶解 / 链式语音为简化移植（非 Tk 像素级）
- RPG 宝箱/选角/BGM 为对话框简版（非桌面全屏动画）；DIY 公主笔刷为粉土+偶发箱
- 拖喂=面板长按后点桌宠（非面板内连续拖拽轨迹）
- 部位感叹无专用 interjection 库时回落 yuqi 分区
- 花瓶：旧存档自动补空瓶；头顶花为像素叠加

### 已达标（代码侧可勾）
- UI：设置可进（**开关=Switch，大小/字体/音量/难度=滑条**）；退出 end+像素溶解；通知≈关宠热键；系统→对话 border5；**音效/语音模式分离 + 语音音量**；**说明/关于/反馈/投稿文案照抄电脑版**
- 面板：背包默认合、18 种含 ×0、喂苍叶、**长按拖喂**、伴侣不吃；**浮窗约 78% 宽、点外侧关闭**；伴侣跟宠/跟旗 + 启动音；**采花戴头顶/摘下**
- 文本：字幕/打字互斥；ring 无框；type_cache；hi/call 强制；**开语音 50/50 抽选**
- 语音：10s 冷却；强制类；hurt；自由抽检；链式对答；**部位点击感叹**；**hungry/email**
- 模式：自由为默认态；工作/跟随/睡眠/音乐/番茄/互动睡眠结束后回自由；旗脚箱数定时宝箱（旗/箱 lime 抠图、搬走再生起点箱、WORK_STACK_OFFSET 环堆、步进语音+自由运送鼓励）/音乐波；**互动睡眠 30s 自动醒**
- 表情/动作：有主意=stand+灯泡→eat2；疑问=站立+黄问号贴纸；伤心 squat→sad1→sad2；比心站立+特效；默认 playPose 不循环
- 大小：手机档 **小144 / 中192 / 大264**（比桌面 96/128/176 约 1.5×，适配高 DPI）
- 伴侣比例：跟随窗仍随主宠三档，立绘按 stand reference_scale 底对齐（勿 FIT 撑满）
- 游戏：采集 clear+差 hurt；暴露；**音游四轨BPM谱+判定线+毫秒窗/长按**；莱姆；**RPG 宝箱骰/猜拳+选角+BGM**；**DIY 双层/擦除/公主/导出**；**GameClear 粒子**
- 家园：室外补 **house/gift** 贴图；布置+经营 MVP；**花瓶插花/取花**
- 所属人：强制认主一次；相伴天+mode_seconds；重置保所属人；启动欢迎/想念
- 系统：**画廊可看图**；**留声全语音分类**；内置曲库默认不打进验收包（`0.2.1-slim`≈48MB），完整 wav 在 `_heavy_assets/music`
- 工具：番茄/秒表计时（**环绕小人 + 自定义分秒**）/日程/生日像素画；本机音乐 URI **或内置曲库**
- 层级：采集在屏幕悬浮直接玩（桌宠+伴侣在下落物之上）；家园/RPG/音游/暴露等全屏仍 `OverlayGate` 收起桌宠
- 进出场：入场（sleep1）/出场像素块溶解；**有智能伴侣时与主宠同步溶解**；**改大小溶解**；**拖拽落地 settle**

## 近期手感补丁（0.2.25-mobile-feel）

- 走动加速（步长 2 / 55ms）；拖拽 move1/2/3 动画
- 大小档：小 192 / 中 264 / 大 360；伴侣侧面略放大
- squat 按 contain 缩放，不按 stand 拉高
- 音乐模式：仅音乐 App 白名单 / CONTENT_TYPE_MUSIC；桌宠语音改 sonification；切歌换色；伴侣同步波形
- 采集：宠不可点 + 触控层置顶，拖动不断档
- 自由站立闲聊间隔可设 10/20/30s（设置页）
- 睡眠：状态变化才刷新；入睡/醒来 sleep1↔sleep2 过渡
- 投喂面板缩小贴底；暴露 QTE 随连击加速

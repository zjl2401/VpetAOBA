# VpetMobile 对照复现清单（诚实版）

> 对照源：`VpetPNG/1.0/PRE_VOICE_BASELINE.md` + `FEATURES.md` + `pet.py`  
> 原则：对照抄行为与常量，不整包搬 `pet.py`；**桌面禁止为本需求大改**。  
> **交差门禁**：Phase 6 按基线逐条勾选通过后才算完成；壳/假 ✅ 不算交差。  
> 可视化计划：Cursor Canvas `vpet-mobile-repro-plan`

## 双端对等基线（1C + KMP）

| 项 | 约定 |
|----|------|
| **基线** | **本清单 MVP（Phase 0–6）= Android / iOS 功能对等范围** |
| **架构** | `shared`（Kotlin Multiplatform）共享 Store/Engine/Catalog；各端自写 UI |
| **Android** | 悬浮窗（`PetOverlayService`）+ 房间模式；本清单手测项以 Android 为准 |
| **iOS 首版** | **仅 App 内房间模式**（系统无等价 `SYSTEM_ALERT_WINDOW`）；可选 PiP，不承诺浮在任意 App 上 |
| **明确不做** | 打字、背单词、天气、云端歌单；桌面「相遇友情 / selecttalk」；Flutter 重写 |

手测路径（双端对照同一表）：认主 →（Android 开悬浮 / iOS 进房间）→ 模式切换 / 喂食 / 家园存读一轮。

## 目标交互（与电脑版对位）

| 电脑版 | 手机版目标 |
|--------|------------|
| 无边框桌宠 + 右键四大菜单 + 快捷键 | **悬浮桌宠**（Android）/ **房间模式**（双端）+ **点宠**四大菜单 |
| 无 Launcher 控制壳 | **App 页只做认主/权限/开桌宠** → Android 启动后可关壳；iOS 认主后进房间 |
| 子功能多为桌宠旁弹窗 | 优先悬浮内完成；全屏页仅无法悬浮实现时用 |

**明确不做**：打字、背单词、天气预报、网易云云端歌单（本机音频可以）。  
**与桌面同 stub**：AI 对话、邀请、×生活。

## 基线核对（`PRE_VOICE_BASELINE` 第十二节 · 手机口径）

### 跳过（需求/平台）
- 打字游戏 G03；背单词 G05–G06；天气预报；网易云云端歌单
- AI / 邀请 / ×生活 → stub（与桌面同）
- Win32 色键 / 全局热键 / 显示层级三档 / ffmpeg 语音裁切 / 投稿本机 zip
- Silent Oath 独立进程全战役（手机为内嵌战役 + DIY）
- 家园经营锄种浇收（H-FARM-TOOLS-V2）玩法 → **已实现 MVP**（见 Phase 续作）
- 桌面「相遇友情 / selecttalk」→ **本阶段手机不做**

### 已知限制（可交差但非桌面像素级）
- GameClear 粒子为简化版；无 ffmpeg 语音裁切缓存
- border5 / 像素溶解 / 链式语音为简化移植（非 Tk 像素级）
- RPG 宝箱/选角/BGM 为对话框简版（非桌面全屏动画）；DIY 公主笔刷为粉土+偶发箱
- 拖喂=面板长按后点桌宠（非面板内连续拖拽轨迹）
- 部位感叹无专用 interjection 库时回落 yuqi 分区
- 花瓶：旧存档自动补空瓶；头顶花为像素叠加

### 已知限制 · iOS
- **无系统级悬浮在其它 App 上**（iOS 禁止等价能力）；首版以房间模式为主，PiP 为弱化选项
- 无 Android 式悬浮权限流；启动页 = 认主 + 进房间
- 真机签名需 Mac + Apple Developer 账号；Windows 仅维护 `shared` + Android + Swift 源
- 精灵/语音首版瘦包（核心帧 + 强制语音），非 Android assets 全量镜像

### 已达标（代码侧可勾 · Android）
- UI：设置可进；退出 end+像素溶解；通知≈关宠热键；系统→对话 border5；**音效/语音模式分离 + 语音音量**
- 面板：背包默认合、18 种含 ×0、喂苍叶、**长按拖喂**、伴侣不吃；伴侣跟宠/跟旗 + 启动音；**采花戴头顶/摘下**
- 文本：字幕/打字互斥；ring 无框；type_cache；hi/call 强制；**开语音 50/50 抽选**
- 语音：10s 冷却；强制类；hurt；自由抽检；链式对答；**部位点击感叹**；**hungry/email**
- 模式：自由/漫步/跟随晕眩 3s/睡眠 peek/工作旗脚箱数定时宝箱/音乐波；**互动睡眠 30s 自动醒**
- 游戏：采集 clear+差 hurt；暴露；音游；莱姆；**RPG 宝箱骰/猜拳+选角+BGM**；**DIY 双层/擦除/公主/导出**；**GameClear 粒子**
- 家园：布置+经营 MVP；**花瓶插花/取花**
- 所属人：强制认主一次；相伴天+mode_seconds；重置保所属人；启动欢迎/想念
- 系统：**画廊用户导入**；**留声用户音频导入**
- 工具：番茄/秒表计时/日程/生日；本机音乐 URI
- 进出场：入场（sleep1）/出场像素块溶解；**改大小溶解**；**拖拽落地 settle**

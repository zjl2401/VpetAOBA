### 家园 / 经营（面板 → 家园）
- 室内外布置：分色家具、滚动面板、可调格子、拖画/右键上色
- **室内房型**：隔板挡路围区；木地板 / 瓷砖铺地（盖住棋盘底）；门洞可穿行；一键模板「空厅 / 一室 / 厨卫角」；笔刷按结构/客厅/卧室/厨房/卫浴分段（与多层、室外作物一并可用）
- **多层楼**：地下室 / 1F / 2F / 3F；相伴满 **7 天**开地下+2F，满 **21 天**开 3F；结构笔刷「上楼/下楼」，站楼梯或点楼层按钮切换；每层独立房间布置
- **房型家具**：客厅/卧室/厨房/卫浴；**需商店购买或合成台制作解锁**；首次进家园发**新手家具礼包**（床桌椅等 + 金币/木材/种子）；床 2×2、沙发/电视柜 3×1、桌/茶几 2×1、地毯 3×2、浴缸 2×2
- **经营模式**（室外 · **完全脱离原作**）：锄/种/浇/收、砍树、钓鱼、采花、商店、合成食物与解锁家具
- **作物外观**：幼苗→抽叶→含苞→成熟分阶段造型；麦/莓/玉 + **苹果（水果）/葡萄（藤蔓）/玫瑰（花卉）**
- **树种布置**：普通树 / 松树 / 果树 / 花树（可砍伐，再生保留原种）
- **轻度种田 P0/P1**：全浇/全收/全种、今日小事预算、土壤干湿、离线微收益、枯萎堆肥；**季节（登录日推进）+ 雨天润泽**；**今日订单**；**小作坊（投入明日取）**；牧场宠「团子」可摸可喂
- 番茄钟完成掉落「露水」；经营面板可用露水浇一格；今日推荐一句
- 采花：可插室内花瓶（再点拔回）；**面板背包点「采下的花」戴头顶 / 摘下**
- 成熟度满分 100（约每小时 +5）；浇水每天最多 2 次，浇后 1 小时成长 ×2；雨天润泽不占次数；久不浇水变慢，不会直接清空
- 统一钱包 `wallet.json`：金币 + 种子/作物/木材/堆肥/露水/果酱等；**每天首次打开登录礼 +1 金币**
- 沙发等家具需**商店购买或合成解锁**后方可新放置；首次家园有新手礼包

### 互动
- 动作：打招呼、下蹲、电话、喂食、睡眠、运送、侧踢、是/否、判断、召唤金目等
- 表情：开心/生气/疑问/伤心/有主意/脸红/wink/点赞等（含背景特效）
- **装扮**：面板「装扮」叠像素配饰（装饰/帽子/眼镜/颈饰/包袋/手持等）；可拖动、缩放、旋转；支持自创画/礼物画/命名素材
- 对话：普通对话等；**AI 对话**入口保留，目前提示「尚未开发完全」
- 工具：办公 / 秒表 / 计时器 / 天气 / 生日
- **办公**（互动 → 工具 → 办公）：番茄 / 待办 / 桌面整理 / 待办展开；待办展开透明可勾选，菜单开关显隐；新增按钮用暖粉色
- **时间显示**（系统设置）：睡眠/音乐/工作旁秒表或定时
- **工作宝箱**：生涯累计每搬满 25 箱获 1 个，进背包可开启

### 面板
- 体力 / 心情 / 食物背包（含经营物资；采下的花可戴/摘）
- **智能伴侣（莲）**：跟随；工作模式可导航
- **莱姆**：练习对战（本地）
- **邀请**：友情达到 **熟人（Lv2）** 后，可邀请对方（伊得/苍叶）来家园做客；面板「邀请」打开**关系卡**（阶段/下一解锁/今日经验/权限树），或桌面家园标题栏「友」
- **友情阶段制**：初识→熟人→好友→挚友→羁绊；每日经验上限 100、同质递减、多样 bonus；家园做客提前至熟人解锁
- 家园放到桌面：标题栏可 **⇄ 自由/🖐 操纵** 切换；**默认暂停背景音乐**，点 ▶ 可恢复（若留声机等已有音乐占用则不可开播）
- **暴露 QTE**（Enter 判定）

### 家园
- 布置：室内/室外；画素材**可多张命名入库**（家园/礼物/RPG 共享图库）；保存/打开/导出家园 JSON
- 室内可用**隔板 + 木地板/瓷砖**围出自定义房型，并布置厨卫卧客家具（购买/制作解锁；有一键房型模板）
- 沙发 / 柜子等需**商店购买或合成解锁**后方可新放置；首次家园有新手礼包
- 左栏：**常用区固定**（区切/模式/经营工具）；**更多**折叠存档·移动·配色；室内「去经营」一键室外经营；导出开创作导出中心
- 室内房间随**相伴天数**增加：1 / 7 / 21 / 45 天 → 最多 4 间
- 多层：B / 1F / 2F / 3F（7 天解锁地下与 2F，21 天解锁 3F）；楼梯上下楼，顶栏可切层
- 室外经营：种田进度条、键位工具动画、合成台画面；首次弹经营说明
- 导出：家园布置、命名素材、礼物画、自创画；RPG DIY 地图；投稿 zip 走「系统 → 社区 → 投稿创意」

### 系统
- **我的 ▶**：所属人、日记、成就、**回忆 ▶**（画廊 / 留声）
- **设置 ▶**：大小、字体、声音、显示层级
- **社区 ▶**：关于 / 问题反馈 / **投稿创意**（分模块打包、仅新增、首次说明、上传渠道；投稿默认无偿公开；称作者菌）/ **操作说明**（含「导出与投稿」、关注与小红书群聊提示）
- 重置 / 退出

### 所属人 / 生日祝福
- 正式包 `PET_ID_FEATURE=False`（无桌宠编号 / 无持有者排名入口）
- **所属人**：启动强制取名，不可跳过；仅一次不可改；重置亦保留
- **我的 → 所属人**：相伴天数、相伴时长；可展开听歌/工作等分项时长
- 启动顺序：先所属人 → 再首次操作说明；每天首次打开另发登录礼 1 金币
- 启动问候：首次认主欢迎；久未打开会说想你
- **互动 → 工具 → 生日祝福 → 设定日期**：到日「生日快乐，+祝福语」
- **互动 → 工具 → 生日祝福 → 赠送礼物**：每年 4/22 桌宠生日俏皮感谢（含昵称、第几个生日、礼物名）；可导出像素画

## 必做维护（仓库卫生）

1. **只保留最新正式包**：`release/Vpet_build_*` 打包后自动只留最近若干份；勿提交到 Git（已在 `.gitignore`）。
2. **勿把 `_old` 媒体编进包**：正式资源用 `bundled/Vpetmusic`、`bundled/Vpetvoice`；备份目录勿再拷进 release。
3. **功能清单以本文为准**：大功能落地后更新本表与 `PRE_VOICE_BASELINE.md` **第十二节 H 段必做**；动画细节不改 `REQUIREMENTS.md` 既有条目。
4. **发布前自测**：自由/漫步/跟随/睡眠/工作（自由拖旗+结束键 / 自定义无结束键·到量到点）/音乐；采集/打字/背单词/音游/RPG；家园布置与经营；面板伴侣与暴露；所属人强制取名 / **相伴天数与时长** / 生日祝福；对照 `PRE_VOICE_BASELINE.md` 第十二章必做表（含 **H-WORK-DEST-FOOT** / **H-WORK-FREE-END** / **H-WORK-CUSTOM-AUTO** 等）。
5. **打包时必须关掉正在运行的 Vpet.exe**，否则 robocopy 会被锁文件卡住，新包进不去。

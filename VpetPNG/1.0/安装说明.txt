【Vpet 桌宠】网盘下载 · 安装与使用说明（Windows）
================================================

一、你下载到的是什么
--------------------
网盘里一般是一个压缩包（.zip），解压后应看到类似内容：

  Vpet/
    Vpet.exe        ← 主程序（必须有）
    start.bat       ← 推荐用这个启动（英文名，不易乱码）
    启动.bat        ← 同上（若显示为乱码可忽略，用 start.bat）
    INSTALL.txt     ← 本说明（英文文件名）
    安装说明.txt    ← 本说明（中文文件名）
    启动说明.txt    ← 本说明（同上，便于查找）
    _internal/      ← 运行库（不要删、不要拆开）
    bundled/        ← 语音 / 音乐 / RPG 资源（不要删）
    README.md       ← 更多说明

注意：不能只拷贝一个 Vpet.exe，整个 Vpet 文件夹都要一起保留。


二、安装步骤（其实不用“安装”）
------------------------------
1. 从网盘下载压缩包到电脑（建议下到「下载」或「桌面」）。
2. 右键压缩包 →「全部解压」/「解压到当前文件夹」。
   - 推荐解压到：桌面\Vpet\ 或 D:\Games\Vpet\
   - 路径尽量短，避免放在过深的文件夹里。
   - 不要解压到需要管理员权限的目录（如 C:\Program Files）。
3. 解压完成后，进入 Vpet 文件夹（里面应能看到 Vpet.exe）。
4. 双击 start.bat（或「启动.bat」/ Vpet.exe）。
5. 看屏幕右下角 / 任务栏：应出现 Vpet 托盘小图标。
6. 用鼠标左键点击托盘图标 → 桌面上会出现桌宠。
7. 在桌宠身上右键 → 打开菜单（模式 / 面板 / 互动 / 系统等）。


三、第一次使用建议
------------------
1. 右键桌宠 → 系统 → 社区 → 操作说明（或按 F1）看用法。
2. 系统 → 我的：所属人 / 日记 / 成就 / 回忆（画廊、留声）。
3. 每天首次打开会领 1 金币登录礼。
4. 若要用语音：设置里打开「语音模式」，首次会后台缓存，稍等即可。
5. 本作品为同人免费桌宠，完整剧情请下载正版《戏剧性谋杀》。
6. 当前功能尚不完全；更多关注与支持，会带来更多更新与优化。


四、常见问题
------------
Q：双击没反应 / 闪一下就没了？
A：请确认 _internal 和 bundled 与 Vpet.exe 在同一文件夹；
   不要单独移动 exe。可用托盘「退出启动器」后重开。
   也可查看日志：按 Win+R，输入  %LOCALAPPDATA%\Vpet  回车，看 pet.log。

Q：解压后只有一层空文件夹？
A：再往里点一层，找到含有 Vpet.exe 的那一层再运行。

Q：杀毒软件拦截？
A：本程序为打包的 Python 桌宠，可能被误报。请加入信任/白名单后重试。

Q：换电脑或重新下载，进度还在吗？
A：同一个人在同一台电脑上，进度保存在系统目录，一般不会丢：
   - 桌宠数据：%LOCALAPPDATA%\Vpet\userdata\
   - RPG 存档与历史最高关卡：%LOCALAPPDATA%\Vpet\rpg\
   若整台电脑重装系统或手动删除上述文件夹，进度才会清空。

Q：桌宠编号每人一样吗？
A：仅网盘分享、未部署发号服务时，编号在本机自动分配，可能与他人重复。
   不影响游玩。

Q：如何完全退出？
A：托盘图标右键 → 退出启动器；或快捷键 Ctrl+Shift+Q。


五、更新版本时怎么装
--------------------
1. 先托盘右键「退出启动器」（或 Ctrl+Shift+Q），关掉旧版。
2. 下载新的更新包（如 Vpet_update_日期.zip），解压。
3. 用解压出的 Vpet 文件夹整体覆盖旧文件夹（或解压到新目录再运行）。
4. 再双击 start.bat /「启动.bat」/ Vpet.exe。
5. 存档一般仍在 %LOCALAPPDATA%\Vpet\，无需手动迁移。
6. 更新包为干净程序包，不含个人日记/家园等记录；个人数据仍读本机目录。

## 已实现功能

### 基础与菜单
- 四大模块：模式 / 面板 / 互动 / 系统（右键打开）
- 左键拖拽移动、透明抠图精灵、**七档**桌宠大小（持久化，按钮切换、无滑条）

- **难度** 低/中/高：影响体力/心情、采集、暴露、莱姆对战
- **重置**：恢复初始设置（**所属人保留**；其余清空；家园重置不清钱包）
- **关于** / **问题反馈**（GitHub / 小红书 / B站 · 关注与 Star；引导下载正版）

### 家园 / 经营（面板 → 家园）
- 室内外布置：分色家具、滚动面板、可调格子、拖画/右键上色
- **经营模式**（室外 · **完全脱离原作**）：锄/种/浇/收、砍树、钓鱼、采花、商店、合成食物与解锁家具
- 采花：可插室内花瓶（再点拔回）；**面板背包点「采下的花」戴头顶 / 摘下**
- 成熟度满分 100（约每小时 +5）；浇水每天最多 2 次，浇后 1 小时成长 ×2
- 统一钱包 `wallet.json`：金币 + 种子/作物/木材等；**每天首次打开登录礼 +1 金币**
- 沙发 / 柜子等需合成解锁后方可新放置

### 互动
- 动作：打招呼、下蹲、电话、喂食、睡眠、运送、侧踢、是/否、判断、召唤金目等
- 表情：开心/生气/疑问/伤心/有主意/脸红/wink/点赞等（含背景特效）
- 对话：普通对话等；**AI 对话**入口保留，目前提示「尚未开发完全」
- 工具：秒表（开始/暂停/结束）/ 计时器（开始/暂停/关闭）/ **番茄钟**（工作运送↔休息睡眠循环；轮次 toast）/ **日程提醒** / **天气预报** / **生日祝福**
- **时间显示**（系统设置）：睡眠/音乐/工作旁秒表或定时；环绕小人随模式换装；结束提示本局与累计时长
- 连点台词、动作结束自动清理特效
- 视觉规格细节以 `REQUIREMENTS.md` / `IMMUTABLE_FILES.md` 为准
- **工作宝箱**：生涯累计每搬满 25 箱获 1 个，进背包可点击开启（金币/物资随机；开箱分档文案）

### 所属人 / 生日祝福
- 正式包 `PET_ID_FEATURE=False`（无桌宠编号 / 无持有者排名入口）

- **我的 → 所属人**：相伴天数、相伴时长；可展开听歌/工作等分项时长
- 启动顺序：先所属人 → 再首次操作说明；每天首次打开另发登录礼 1 金币
- 启动问候：首次认主欢迎；久未打开会说想你
- **互动 → 工具 → 生日祝福 → 设定日期**：到日「生日快乐，+祝福语」
- **互动 → 工具 → 生日祝福 → 赠送礼物**：每年 4/22 桌宠生日俏皮感谢（含昵称、第几个生日、礼物名）；可导出像素画

## 必做维护（仓库卫生）

1. **只保留最新正式包**：`release/Vpet_build_*` 打包后自动只留最近若干份；勿提交到 Git（已在 `.gitignore`）。
2. **勿把 `_old` 媒体编进包**：正式资源用 `bundled/Vpetmusic`、`bundled/Vpetvoice`；备份目录勿再拷进 release。
3. **功能规格以必做表为准**：大功能落地后更新本表与 `PRE_VOICE_BASELINE.md` **第十二节 H / J / K**；动画细节不改 `REQUIREMENTS.md` 既有条目。
4. **发布前自测**：对照 `PRE_VOICE_BASELINE.md` 第十二章 **A～J** 打勾；**K** 项未做不得写成已完成；含工作旗脚/自由结束键/自定义自动结束、投稿包桌面命名、是否抠图、开心跳动等。
5. **打包时必须关掉正在运行的 Vpet.exe**，否则 robocopy 会被锁文件卡住，新包进不去。
6. **干净公开包**：无手机版、无本机个人路径/隐私信息。

## 已实现功能

- **难度** 低/中/高：影响体力/心情、采集、暴露、莱姆对战
- **重置**：恢复初始设置（**所属人保留**；其余清空）
- **关于** / **问题反馈**（GitHub / 小红书 / B站 · 关注与 Star；引导下载正版）

### 互动
- 动作：打招呼、下蹲、电话、喂食、睡眠、运送、侧踢、是/否、判断、召唤金目等
- 表情：开心/生气/疑问/伤心/有主意/脸红/wink/点赞等（含背景特效）
- 连点台词、动作结束自动清理特效
- 视觉规格细节以 `REQUIREMENTS.md` / `IMMUTABLE_FILES.md` 为准

### 面板
- 体力 / 心情 / 食物背包
- **智能伴侣（莲）**：跟随；工作模式可导航
- **莱姆**：练习对战（本地）
- **暴露 QTE**（Enter 判定）

### 系统
- **我的**：所属人、生日祝福、日记、日程、回忆（画廊/留声）、成就等
- **设置**：大小、字体、声音、显示层级
- AI 对话、天气预报、重置、关于、反馈、退出

### 所属人 / 生日祝福
- 正式包 `PET_ID_FEATURE=False`（无桌宠编号 / 无持有者排名入口）
- **所属人**：启动强制取名，不可跳过；仅一次不可改；重置亦保留
- 启动顺序：先所属人 → 再首次操作说明
- **生日祝福 → 设定日期**：到日「生日快乐，+祝福语」
- **生日祝福 → 赠送礼物**：每年 4/22 桌宠生日俏皮感谢（含昵称、第几个生日、礼物名）

### 语音与音乐
- 场景 / 随机语音（`voice_system`）；音乐模式下不播语音
- BGM 漫步 + 音游谱面缓存
- 声音设置可开关与资源检查

## 必做维护（仓库卫生）

1. **只保留最新正式包**：`release/Vpet_build_*` 打包后自动只留最近若干份；勿提交到 Git（已在 `.gitignore`）。
2. **勿把 `_old` 媒体编进包**：正式资源用 `bundled/Vpetmusic`、`bundled/Vpetvoice`；备份目录勿再拷进 release。
3. **功能清单以本文为准**：大功能落地后更新本表；动画细节不改 `REQUIREMENTS.md` 既有条目。
4. **发布前自测**：自由/漫步/跟随/睡眠/工作/音乐；采集/打字/背单词/音游/RPG；面板伴侣与暴露；所属人强制取名 / 生日祝福；对照 `PRE_VOICE_BASELINE.md` 第十二章必做表。
5. **打包时必须关掉正在运行的 Vpet.exe**，否则 robocopy 会被锁文件卡住，新包进不去。

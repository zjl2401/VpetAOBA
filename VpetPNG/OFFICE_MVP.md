# 桌宠办公 · 陪伴式轻办公

> 原则：陪你工作一小会儿；离线优先；少弹窗；清文件只提示不自动删。

## 信息架构

| 入口 | 内容 |
|------|------|
| 互动 → 工具 → **办公** | 番茄钟 · 今日待办 · 桌面整理 · 待办展开 |
| 办公 → **更多** | 剪贴板 · 常用语 · 快捷启动 · 日程 · 剪贴板监控 |
| 互动 → **工具** | 办公 · 秒表 · 计时器 · 天气 · 生日 |

待办展开：默认隐藏；透明底可勾选；菜单项展开/收起。办公新增按钮用暖粉，避免深蓝。

## 能力与存储

| 能力 | 说明 | 存储 |
|------|------|------|
| 番茄钟 | 工作↔休息；完成掉家园露水 | 运行时 + 桌面钟 |
| 今日待办 | 增删勾选；旁最多 3 条展开条 | `office_todos.json` |
| 桌面整理 | 扫桌面+下载：大文件/同名/旧下载；「打开位置」 | 无落盘（即时扫描） |
| 剪贴板历史 | 最近 30 条；可关监控 | `office_clipboard.json` |
| 常用语 | 模板一键复制 | `office_phrases.json` |
| 快捷启动 | 程序/文件夹/URL | `office_launchers.json` |
| 日程提醒 | 原工具能力 | `schedules.json` |

## 明确不做

- 一键自动删文件 / 强制清理
- 与 Copilot 拼全能办公
- 把办公功能堆回「工具」一级列表（除办公入口本身）

## 隐私

- `office_allow_clipboard` 可关
- 桌面整理仅本地路径扫描，不上传
